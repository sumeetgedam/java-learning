# Lesson 8: Arrays and Strings

## Questions

1. What is an array?
2. Why do array indexes start at zero?
3. Can an array change size after creation?
4. What does `ArrayIndexOutOfBoundsException` mean?
5. When would you use an enhanced `for` loop?
6. Why is `String` immutable?
7. Why should `equals()` be used instead of `==` for string content?
8. When would you use `StringBuilder`?
9. What does `substring(1, 3)` return from `"Java"`?

## My summary

```text
Arrays have a fixed size and store values of one type.
Strings are immutable objects, so operations create new strings rather than changing the original.
StringBuilder is useful for repeated text modification
```
