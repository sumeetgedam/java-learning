# Lesson 2: Variables and Types

## Questions

1. What are the eight primitive types?
2. What is the difference between a primitive variable and a reference variable?
3. What does assignment do for primitive values?
4. What does assignment do for object reference?
5. What is the difference between `==` and `.equals()`?
6. What does `final` mean for a primitive variable?
7. What does `final` mean for an object reference?

## My summary

- Primitive assignments copies the value
- Objects are accessed through references
- `==` compares primitive values, for objects it compares references
- `.equals()` usually compares object contents.
- `final` variable cannot be reassigned
- `final` prevents changing the reference, not necessarily the object.

```text
A primitive variable directly contains a value.
A reference variable contains a reference to an object.
Assigning a primitive copied its value
assigning an object variable copies its reference
```
