# Lesson 3: Operators and Control Flow

## Questions

1. What is the result of `10 / 3` when both operands are `int`?
2. What does `%` return?
3. What is the difference between `&&` and `||`?
4. What is short-circuit evaluation?
5. When would you use `if-else` instead of `switch`?
6. When would you use a `for` loop instead of a `while` loop?
7. What is the difference between `break` and `continue`?
8. Why can a loop become infinite?

## My summary

```text
Operators produce values, comparisons produce booleans, 
conditions choose execution paths, and loops repeat execution while a condition remains true
```
