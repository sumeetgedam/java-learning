# Lesson 4: Methods

## Questions

1. What is the purpose of a method?
2. What is the difference between a parameter and an argument?
3. What does `void` mean?
4. What does `return` statement do?
5. Is Java pass-by-value or pass-by-reference?
6. Why can a method mutate an object passed to it?
7. What is method overloading?
8. Can methods be overloaded only by changing the return type?
9. What is variable scope?

## My summary

```text
A method receives values through parameters, performs an operation,
and may return a result.
Java always passes arguments by value; for objects, that value is a copy of the reference.
```
