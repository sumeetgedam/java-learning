# Java Learning

This repository contains hands-on exercise for:

- Core Java
- Spring and Spring Boot
- Persistence
- Security
- Kafka
- Microservices
- System Design
- Production Engineering
- Low-latency Java

## Learning rules

1. Every concept must have executable code.
2. Every important concept should have a test.
3. Each topic should include a short README.
4. Prefer small experiments over large applications.
5. Record mistakes and interview questions.
6. Avoid copying solutions without understanding them.
